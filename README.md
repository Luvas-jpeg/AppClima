# AppClima
Será um projeto da Aula de Flutter na Faculdade

Idéia PRincipal:

Criar um app de previsão de tempo normal mas, que o usuário possa utilizar ele como GPS, porém no caminho, teria a previsão de tempo, por exemplo, a rota dura 2 horas, e uma parte do trajeto, está definido que daqui 1 hora. tem uma possibilidade de chuva.
